Задание №3 — ChangeDetectorRef + OnPush

Часть 1 — markForCheck()

Count: {{ count }}

ngDoCheck вызван: {{ checkCount }} раз

Что проверяем

Без markForCheck значение count изменяется внутри setTimeout, но OnPush-компонент не помечается для проверки.

markForCheck помечает компонент для проверки в ближайшем цикле Change Detection.

markForCheck сам по себе не выполняет синхронную проверку компонента.

Часть 2 — detectChanges()

detectChanges выполняет проверку текущего компонента и его дочернего дерева немедленно.

В отличие от markForCheck, detectChanges не ждёт следующего общего цикла Change Detection.

Часть 3 — detach()

detach удаляет компонент из обычного дерева Change Detection. Состояние компонента продолжает изменяться, но Angular больше не проверяет этот view автоматически.

Часть 4 — reattach()

reattach возвращает компонент обратно в дерево Change Detection. После этого компонент снова участвует в обычных проверках Angular.
