Задание №1 — ChangeDetectionStrategy.OnPush

ParentComponent передаёт объект пользователя в ChildComponent.

При обычной мутации изменяется свойство объекта, но ссылка на объект остаётся прежней.

ChildComponent использует OnPush, поэтому изменение внутреннего свойства объекта само по себе не является новым Input.

Минимальное исправление — создать новый объект с помощью spread, чтобы ссылка изменилась.
